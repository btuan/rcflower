# Flower assets

Generated by `tools/flower/` (Blender). Don't hand-edit; rerun the scripts.

- `flower_<mood>.glb` — skinned glTF per preset. `blender -b -P tools/flower/build_flower.py -- --export`
- `gallery/` — parameter-sweep contact sheets. `blender -b -P tools/flower/render_gallery.py` then `python3 tools/flower/contact_sheet.py assets/flower/gallery`
- `anim/` — spring-model clips (bounce, jerk, tilt, shake, wind). `blender -b -P tools/flower/simulate.py`
- `Flower*.png` — original reference art.
